# في بيتنا العُماني

موقع تعليمي تفاعلي (HTML/CSS/JS) بلا مكتبات خارجية ولا خوادم. يعمل دون إنترنت بعد أول تحميل.

## التشغيل محليًا
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`. (فتح index.html مباشرة يعمل أيضًا، لكن العمل دون إنترنت يحتاج http/https.)

## النشر على GitHub Pages
1. أنشئ مستودعًا وارفع محتويات هذا المجلد (index.html في الجذر).
2. Settings → Pages → Branch: main / root → Save.
المسارات كلها نسبية.

## إضافة الصور
لوحة الأخصائية ← الصور ← اختيار ملف ← معاينة ← حفظ. أو استبدل الملف يدويًا بجانب `index.html` بنفس الاسم (water.png, apple.png, ball.png, book.png, blanket.png, help.png, kitchen.png, majlis.png, bedroom.png, house.png).
الصور الموجودة الآن **رسوم مؤقتة** يجب استبدالها بصور واقعية.

## إضافة التسجيلات الصوتية
لوحة الأخصائية ← الأصوات ← رفع ← استماع ← حفظ.
أو ضع الملفات في `sounds/` بأسماء المفاتيح: `q_water.mp3`, `c_water.mp3`, `p_1.mp3`, `ins_what.mp3` … (القائمة الكاملة في `data.js` وفي تبويب الأصوات). الصيغ: mp3 / m4a / wav / ogg.
إن لم يوجد تسجيل يُستخدم صوت المتصفح التجريبي (ليس بلهجة عُمانية) ويمكن إيقافه من «تخصيص الأنشطة».

## نقل الإضافات إلى GitHub
التخزين في المتصفح لا يحدّث الموقع المنشور. من لوحة الأخصائية ← التصدير ← «تنزيل الصور والأصوات المضافة»، ثم ضع الصور بجانب `index.html` والتسجيلات في `sounds/` وارفعها.

## الخصوصية
كل البيانات (إعدادات، نتائج، جلسات، وسائط) محفوظة محليًا في المتصفح. استخدم رمزًا للطفل لا اسمه. الرقم السري الافتراضي للوحة: 1234 (غيّره من التخصيص).
